# Introduction_to_OOP

##  Модуль Product|Category
В данных модулях отображены классы, также произведена инициализацию.
- у класса Product определены  атрибуты: name, description, price, quantity.
- у класса Category имеет два атрибута класса: количество категорий (count_category) и количество товаров (count_product). 

## Задание 14.2
- В данном модуле мы реализовываем работу с приватными атрибутами, к которым нельзя обращаться от объекта, но можно обращаться внутри класса;
- Используем декоратор property для создания геттера с выводом списка товаров;
- В класс-методе класса Product необходимо вызывать метод-конструктор __init__  от класса продуктов, а созданный объект возвращать как результат работы метода;
